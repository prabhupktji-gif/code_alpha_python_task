# CodeAlpha Python Programming Internship

This repository contains the Python projects I completed during my **CodeAlpha Python Programming Internship**.

The projects helped me practice basic Python concepts such as loops, conditions, lists, dictionaries, functions, user input, random values, and file handling.

## Projects Included

### 1. Hangman Game

A simple console-based Hangman game where the player tries to guess a hidden word one letter at a time.

**Features:**

* Contains 5 predefined words
* Randomly selects a word
* Player guesses one letter at a time
* Maximum of 6 incorrect guesses
* Displays the progress of the word
* Console-based gameplay

**Concepts Used:**

* Lists
* Strings
* `random`
* `while` loop
* `if-else`
* User input

---

### 2. Stock Portfolio Tracker

A simple program that calculates the total value of stocks based on the stock name and quantity entered by the user.

The stock prices are stored manually in a Python dictionary.

**Features:**

* Displays available stocks
* Takes stock name and quantity from the user
* Calculates the value of each stock
* Calculates the total investment
* Saves the final result in a text file

**Concepts Used:**

* Dictionary
* Input and output
* Loops
* Conditional statements
* Basic arithmetic
* File handling

---

### 3. Basic Chatbot

A simple rule-based chatbot that responds to a few predefined messages entered by the user.

**Features:**

* Responds to greetings
* Answers simple questions
* Continues chatting until the user exits
* Uses predefined responses

**Concepts Used:**

* Functions
* `if-elif-else`
* Loops
* Strings
* User input and output

## How to Run

1. Install Python on your computer.
2. Clone this repository.
3. Open the required project folder.
4. Run the Python file using:

```bash
python filename.py
```

For example:

```bash
python hangman.py
```
